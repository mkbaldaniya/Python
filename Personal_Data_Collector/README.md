# 📋 Interactive Personal Data Collector

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)

## 🚀 Overview
A lightweight data collection script designed to capture basic user information, analyze data types, and perform simple logical computations based on the input.

## ✨ Features
- **Data Collection**: Collects Name, Age, Height, and Favorite Number.
- **Type Inspection**: Dynamically analyzes and displays the Python data types for all inputs.
- **Memory Allocation**: Reveals the internal memory address (`id()`) of the variables.
- **Age Computation**: Automatically estimates the user's birth year based on the provided age.

## 💻 Usage
```bash
python data_collector.py
```
