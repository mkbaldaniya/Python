## 🚀 Overview
A specialized analytical tool for manipulating and inspecting n-dimensional arrays using NumPy. Perfect for scientific computing tasks and matrix operations.

## ✨ Features
- **Array Generation**: Create and initialize 1D, 2D, and 3D NumPy arrays.
- **Matrix Operations**: Advanced indexing, slicing, and mathematical operations across multiple axes.
- **Array Manipulation**: Seamlessly combine, concatenate, or execute horizontal/vertical splits on data structures.
- **Filtering & Sorting**: Fast searching, filtering, and sorting algorithms applied directly to matrices.
- **Statistical Aggregation**: Instantly compute Sum, Mean, Median, Standard Deviation, and Variance.

## 💻 Usage
```bash
python numpy_analyzer.py
```
