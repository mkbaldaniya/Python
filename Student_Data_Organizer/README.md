# 🎓 Student Data Organizer

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)

## 🚀 Overview
The **Student Data Organizer** is a robust Command-Line Interface (CLI) application built in Python. It allows users to manage student records efficiently, providing full CRUD (Create, Read, Update, Delete) functionality.

## ✨ Features
- **Add Students**: Input multiple student records including ID, name, age, grade, and subject.
- **View Records**: Display a beautifully formatted list of all stored student data.
- **Update Information**: Selectively modify a student's name, age, grade, or subject using their unique ID.
- **Delete Records**: Seamlessly remove student entries from the system.
- **Subject Analysis**: Instantly view a consolidated list of all unique subjects offered.

## 💻 Usage
Run the script in your terminal and follow the interactive menu prompts:
```bash
python student_organizer.py
```
