# 🏢 Employee Management System (OOP)

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)

## 🚀 Overview
An Object-Oriented Programming (OOP) project modeling a corporate hierarchy. It features base and derived classes to manage standard persons, employees, and managers within an organization.

## ✨ Features
- **Class Hierarchy**: Implements `Person`, `Employee`, and `Manager` objects.
- **Data Encapsulation**: Dedicated setter and getter methods for instance variables.
- **Batch Creation**: Instantiate and configure multiple objects in a single continuous loop.
- **Role-Specific Data**: 
  - *Persons*: Track Name and Age.
  - *Employees*: Inherit from Person, adds ID and Salary.
  - *Managers*: Inherit from Employee, adds Department.
- **Unified Display**: Formatted terminal output for all organizational roles.

## 💻 Usage
```bash
python employee_management.py
```
