# 🔢 Pattern Generator & Number Analyzer

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)

## 🚀 Overview
A dual-purpose mathematical CLI utility that generates visual terminal patterns and performs deep analysis on sequential numerical ranges.

## ✨ Features
- **Dynamic Pattern Generation**: Creates ascending asterisk (`*`) triangle patterns based on user input.
- **Range Analysis**: Scans a user-defined range of numbers.
- **Even/Odd Classification**: Automatically classifies each number within the range.
- **Cumulative Summation**: Calculates the total sum of all numbers processed in the range.

## 💻 Usage
```bash
python pattern_analyzer.py
```
