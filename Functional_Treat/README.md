# 🧮 Data Analyzer & Transformer

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)

## 🚀 Overview
An interactive numerical data processing tool that demonstrates the power of Python's built-in functions, lambda expressions, and recursive algorithms.

## ✨ Features
- **Data Ingestion**: Dynamically input an array of numerical values.
- **Statistical Summary**: Instantly calculate Minimum, Maximum, Sum, and Average values.
- **Recursive Factorial**: Calculate the factorial of any number using advanced recursive functions.
- **Threshold Filtering**: Utilize Lambda functions to filter datasets based on user-defined thresholds.
- **Advanced Sorting**: Sort data arrays in ascending or descending order on the fly.

## 💻 Usage
```bash
python data_transformer.py
```
