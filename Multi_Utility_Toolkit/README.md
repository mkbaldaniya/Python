# 🧰 Multi-Utility Toolkit

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)

## 🚀 Overview
A comprehensive, multi-module toolkit consolidating essential developer utilities into a single, interactive CLI dashboard.

## ✨ Features
- **Time Operations**: Current datetime, date differences, custom formatting, stopwatch, and countdown timers.
- **Advanced Math**: Factorials, compound interest, trigonometric calculations, and geometric area solvers.
- **Random Generators**: Generate random numbers, lists, secure passwords, and One-Time Passwords (OTPs).
- **UUID Generation**: Create universally unique identifiers for database and backend needs.
- **File System Management**: Integrated custom module for creating, reading, writing, and appending to local files.

## 💻 Usage
```bash
python multi_utility.py
```
