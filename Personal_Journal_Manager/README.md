# 📓 Personal Journal Manager

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)

## 🚀 Overview
A secure, file-based CLI application for writing and managing personal journal entries. Each entry is automatically time-stamped and safely stored in a local text file (`journal.txt`).

## ✨ Features
- **Timestamped Entries**: Automatically logs the exact date and time for every new entry.
- **Batch Entry**: Add multiple journal entries in a single session.
- **Smart Search**: Search past entries using keywords or specific dates.
- **Persistent Storage**: Utilizes Python's file I/O capabilities for reliable data retention.
- **Clear Records**: Option to securely delete all journal entries when a fresh start is needed.

## 💻 Usage
```bash
python journal_manager.py
```
